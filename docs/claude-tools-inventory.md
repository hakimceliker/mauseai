# Claude Araç Envanteri

Bu dosya Claude hesabının gerçek eklenti/uygulama/MCP bağlantıları görüldüğünde doldurulacaktır.

## Durum

- `planned`: MouseAI’de görev tanımı var, Claude bağlantısı henüz doğrulanmadı.
- `connected`: Araç gerçekten çağrılabiliyor ve test kanıtı var.
- `blocked`: İzin, kota, kimlik doğrulama veya güvenlik sorunu var.

Claude tarafında araç adı, sağlayıcı, yetki, maliyet, veri kapsamı, fallback aracı ve test kanıtı olmadan hiçbir araç üretim akışına eklenmeyecektir.
